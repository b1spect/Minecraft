# Minecraft Private Server Scanner

Веб-приложение для поиска и мониторинга приватных серверов Minecraft.

## 🚀 Запуск

```bash
cd /workspace/minecraft-scanner
npm start
```

Откройте браузер: **http://localhost:3000**

## 🔍 Возможности

### Автоматическое сканирование
- Сканирование диапазонов IP адресов
- Поиск серверов в локальных сетях (192.168.x.x, 10.x.x.x, 172.16.x.x)
- Проверка публичных подсетей

### Ручная проверка
- Проверка конкретного IP адреса
- Указание порта (по умолчанию 25565)
- Мгновенный результат

### Мониторинг
- Автообновление статуса каждые 30 секунд
- Отслеживание онлайна игроков
- Информация о версии сервера
- Отображение MOTD (описания сервера)
- Измерение пинга

### Фильтрация
- Исключение популярных публичных серверов (Hypixel, Mineplex и др.)
-只显示 приватные сервера игроков

## 📡 API

| Endpoint | Method | Описание |
|----------|--------|----------|
| `/api/servers` | GET | Получить все найденные сервера |
| `/api/scan` | POST | Запустить сканирование диапазона |
| `/api/stop` | POST | Остановить сканирование |
| `/api/check` | POST | Проверить конкретный IP |
| `/api/server/:ip/:port` | DELETE | Удалить сервер из списка |
| `/api/servers` | DELETE | Очистить весь список |
| `/api/stats` | GET | Статистика сканирования |

## 💡 Как использовать

1. **Проверка конкретного сервера:**
   - Введите IP адрес в поле "Проверить конкретный IP"
   - Нажмите "Проверить"
   - Если сервер найден и не является публичным, он добавится в список

2. **Сканирование диапазона:**
   - Укажите начальный и конечный IP диапазон
   - Выберите порт (или оставьте 25565)
   - Нажмите "Начать сканирование"
   - Следите за прогрессом в реальном времени

3. **Управление найденными серверами:**
   - Просматривайте информацию о каждом сервере
   - Удаляйте ненужные сервера
   - Очищайте весь список при необходимости

## ⚙️ Технические детали

- **Backend:** Node.js + Express
- **Frontend:** HTML5 + CSS3 + Vanilla JavaScript
- **Minecraft Protocol:** mcstatus библиотека
- **Обновление:** Автообновление каждые 5 секунд (frontend), 30 секунд (статус серверов)

## ⚠️ Важно

- Сканирование больших диапазонов IP может занять много времени
- Некоторые сервера могут блокировать частые запросы
- Приложение исключает известные публичные сервера из результатов
- Для доступа к приватным серверам в локальных сетях нужно быть в той же сети
